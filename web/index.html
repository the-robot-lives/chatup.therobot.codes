MD ▾

Your LLM chats, as clean Markdown.

Chat to Markdown is a browser extension that turns conversations from the major AI chat UIs into portable Markdown — or API-format YAML — with a floating panel: preview, copy, download. Everything runs locally.

Download latest zip Source on GitHub

Works where you chat

ChatGPT Claude (incl. share pages) Gemini Le Chat (Mistral) use.ai (Grok-powered) Open WebUI — any self-hosted instance grok.com · chat.groq.com (experimental)

What you get

Markdown mode

Front-matter header, ## User / ## Assistant turns separated by * * *, faithful code blocks, tables, lists, and math.

YAML mode

The full thread as an API-format payload: a messages: list with role:/content: entries — ready for evals and replay.

Tool calls, summarized

Search/browse/code chips collapse to tool-call made to … / tool-call-response: … lines instead of their payload.

Local-only

No accounts, no analytics, no servers. The extension reads the page you're on and hands the result to you. Privacy.

Install in 30 seconds (developer mode)

  1. Grab the latest release zip and unzip it.
  2. Open chrome://extensions (or edge://extensions) and enable Developer mode.
  3. Click Load unpacked and select the unzipped folder.
  4. Open any supported chat and hit the floating MD ▾ button.
